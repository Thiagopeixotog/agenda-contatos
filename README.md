# agenda-contatos

Aplicação em em Python, feita em dupla, para cadastrar, listar, buscar e remover contatos via terminal.

## Funcionalidades

- Cadastrar um novo contato (nome, telefone, email)
- Listar todos os contatos cadastrados
- Buscar um contato pelo nome
- Remover um contato

## Como executar

'''
python agenda.py
'''
